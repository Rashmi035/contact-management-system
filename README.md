
# Contact Management System

A beginner-friendly Python project to manage contacts.

## Features
- Add contacts
- View all contacts
- Search contacts
- Update contacts
- Delete contacts
- Prevent duplicate phone numbers
- Display contacts alphabetically

## Technologies Used
- Python
- JSON for storing contacts

## How to Run
1. Install Python.
2. Open this folder in VS Code.
3. Run `python contact_manager.py` in the terminal.
